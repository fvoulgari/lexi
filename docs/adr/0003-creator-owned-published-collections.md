# Creator-owned published collections and stable card references

A collection is an ordered set of references to stable vocabulary cards in one explicit language pair, while learning state remains personal to the learner, card and practice direction. Its creator may publish it without an editorial queue, but must explicitly confirm exposure of their own private cards; foreign private and restricted legacy cards cannot be published through a collection.

This supersedes ADR 0002's private-only collections and administrator-only publication policy **only for creator-owned cards published through this flow**. The card creator retains ownership after publication, so another collection owner cannot edit or publish restricted cards; the existing shared-library editor/admin permissions remain unchanged. Unpublishing a collection does not silently withdraw its already published cards from other collections. Creators can withdraw individual cards, and all references and practice access re-check the resulting audience. Archival, unpublishing and removing references preserve learning history.

Keep existing Italian–Greek card columns and snapshot keys as compatibility storage rather than rewriting historical data. Generic card APIs use source/target text aliases and explicit language identifiers; new direction identifiers use language codes while historical Italian–Greek direction identifiers remain unchanged. This avoids splitting existing progress or rewriting reviews. The existing Italian–Greek grammar/import/export screens retain their language scope; the new collection workspace handles the additional pairs.
