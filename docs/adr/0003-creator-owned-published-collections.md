# Creator-owned published collections and stable card references

A collection is an ordered set of references to stable vocabulary cards in one explicit language pair, while learning state remains personal to the learner, card and practice direction. A creator may publish a collection without an editorial queue, but must confirm each of their own private cards for that collection. Restricted legacy cards cannot be exposed, and a reference to another creator's accessible card cannot grant or extend access.

This supersedes ADR 0002's private-only collections **only for explicitly confirmed collection publication grants**. Private cards retain their owner and private stored visibility. Another learner may read one only while a confirmed reference exists in a published collection owned by that card's creator. Unpublishing/deleting the collection or removing its reference removes that grant; other valid creator-owned grants can retain access. Independently published library cards and existing editor/admin restrictions are unchanged. Removing access never removes references, reviews or learner/card/direction progress, so republishing restores that same learning state.

Italian–Greek cards use the original Italian and Greek text slots regardless of the collection pair's canonical order. The generic API and both practice renderers map text using explicit language IDs. Migration normalizes reversed draft card text slots in place while preserving IDs, language-named grammar, review snapshots and progress keys; old snapshots remain interpretable through their own language IDs. Other pairs continue to use generic source/target aliases without introducing more language-specific columns.
