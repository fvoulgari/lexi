# Language-agnostic card text and grammar

A vocabulary card's two texts are identified by explicit supported-language IDs, not by their position in a pair. Adding a learning language therefore needs no new text or grammar columns: common fields (text, word type, unit reference, tags, notes) are shared by every card, and optional grammar is described by definitions keyed by language ID. Existing Italian and Greek definitions keep their values and names, while English and Danish cards use common fields only. Card language IDs are fixed at creation; a different pair is a different card, but practice direction remains changeable.

This extends ADR 0003's explicit language-ID mapping from Collections and practice into card authoring and grammar. The original Italian/Greek storage columns remain the compatibility slots for legacy text and grammar, and CSV format v2 (ADR 0004) carries the language IDs across exchange. No automatic translation, generated speech or new learning language is introduced, and no stored card, review or progress row is rewritten.
